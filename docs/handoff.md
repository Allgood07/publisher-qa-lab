# Текущий статус

**Этап:** локальный пилот принят, добавлены отдельные проверки неизменности опубликованной версии, валидации черновика, отображения текста без потерь и публичной страницы при ширине 360 px. GitHub Actions зелёный по подтверждению пользователя; в переданном HTML подтверждено `9` успешных тестов. Приёмка из чистого клона завершена. Все пять пользовательских ролей Codex проверены в отдельном учебном прогоне. Отдельная [проверка собственной бесплатной страницы Site.pro](sitepro-check.md) тоже завершена; страница оставлена опубликованной с V2 и внутренней текстовой ссылкой, подтверждённых дефектов нет. Это не результат локального набора.

**Допроверка Site.pro:** авторские поля «Текст», «Название якоря», «Веб-адрес» (пустой) и выбор внутренней страницы проверены через `node` + Playwright 1.64.1 (`chromium.connectOverCDP`). Ссылка ведёт к заголовку: `Tab` + `Enter` при 1280 px, касание при 360 px, оба гостевых контекста без входа. «Форма» и «Кнопка» помечены премиальными, поэтому отправка формы посетителя не проверена. Тариф не менялся. [Наблюдения и ограничения](sitepro-check.md#поля-редактора-и-текстовая-ссылка).

**Локальный пилот:** TypeScript, отдельный loopback-процесс на порту, назначенном ОС, один сценарий Chromium. Два штатных прогона дали `1 passed` без повторов. Между ними контрольный прогон упал после сохранения черновика с маркером `PILOT_CONTROLLED_FAILURE`; внешняя проверка по PID и TCP подтвердила остановку в пределах 5 секунд. Повтор подтвердил чистый старт. Фактические команды и результаты — в [контракте пилота](pilot.md), запуск и HTML-отчёт — в [README](../README.md).

**Расширение:** `tests/published-snapshot.spec.ts` проверяет V1 у посетителя, сохранение V2 после перезагрузки редактора и неизменную V1 в новом гостевом контексте. Фикстура запускает отдельный сервер на каждый тест. Рабочий сервис не менялся; временная копия с намеренно неверным обновлением снимка дала `1 failed` на ожидании V1, штатная версия дала `1 passed` до и после. `npm run typecheck` прошла, `npm run test:cleanup` подтвердила очистку, `npm test` дала `2 passed`. Команды и подробности — в [результатах](pilot.md#отдельная-проверка-опубликованной-версии).

**Валидация:** добавлен `tests/draft-validation.spec.ts`: четыре HTTP 400 для пустых или пробельных полей и один интеграционный тест на сохранность V2 в редакторе и V1 у посетителя после отказа V3. Сервис не менялся. `npm run typecheck` — успешно; `npx playwright test tests/draft-validation.spec.ts --project=chromium --workers=1 --retries=0` — `5 passed`; `npm test` — `7 passed`. Переданы контракт, новый тест, фикстура, общая проверка содержимого, сервис и конфигурация в отдельную сессию `pi -p --no-session --no-tools …`: согласовано, блокеров нет. [Шаблон ревью](reviewer.md) пригоден для следующих задач.

**Текст без потерь:** `tests/draft-text.spec.ts` проверяет точные поля редактора, буквальное отображение `<em>` и сохранение двойного пробела в видимом предпросмотре. Первое независимое ревью нашло ложноположительный вариант при проверке CSS родителя; заменили её на сравнение `innerText`, повторное ревью сняло блокер. `npm run typecheck` — успешно, `npx playwright test tests/draft-text.spec.ts --project=chromium --workers=1 --retries=0` — `1 passed`, `npm test` — `8 passed`. В отдельной временной копии с намеренным схлопыванием пробела точечный прогон дал `1 failed`. Рабочий сервис не менялся. [Подробности](pilot.md#валидный-текст-без-потерь).

**Узкий экран:** `tests/narrow-publication.spec.ts` подтвердил реальный локальный дефект: при ширине 360 px длинный текст увеличивал ширину прокрутки до 772 px. `overflow-wrap: anywhere` в `src/server.ts` исправил его; тот же тест прошёл. Ревьюер нашёл пробел при скрытом обрезании предком; проверка границ усилена, намеренное обрезание во временной копии приводит к падению, повторное ревью без блокеров. `npm run typecheck` — успешно, `npx playwright test tests/narrow-publication.spec.ts --project=chromium --workers=1 --retries=0` — финальный `1 passed`, `npm test` — `9 passed`. [Подробности и trace](pilot.md#публичная-страница-при-ширине-360-px).

**CI:** добавлен `.github/workflows/qa.yml` (PR, push в `main`, ручной запуск; Ubuntu 24.04, Node.js 22, проверка типов, полный Chromium, HTML-артефакт даже после падения). `git ls-remote --tags` подтвердил SHA официальных actions; `actionlint .github/workflows/qa.yml` прошёл. Во временной копии на macOS/Node 22.23.5 при `CI=true` прошли `npm ci`, `npm run typecheck`, `npx playwright install chromium` и `npm test` (`9 passed` и HTML). После удаления отчёта контрольный `PILOT_FORCE_FAILURE=1 npm test` дал ожидаемый код 1 и создал новый HTML. Отдельная сессия Pi согласовала workflow без блокеров. Эти локальные результаты не подтверждают запуск GitHub runner, `--with-deps` на Ubuntu или загрузку артефакта. [Детали проверки](pilot.md#проверка-настройки-ci).

**Приёмка:** чистый клон GitHub `0c9883f` (macOS arm64, Node.js 22.23.5, пустые npm/браузерные кэши). Прошли `npm ci`, `npx playwright install chromium`, `npm run typecheck`, точечный прогон (`1 passed`), `npm test` (`9 passed`) и `npm run test:cleanup` с ожидаемым падением внутри и успешным подтверждением остановки. Повтор штатных прогонов зелёный, HTML открыт в Chromium. Учебная страница Site.pro без входа показала V2 и вернула HTTP 200 на ширине 360 px. Финальное статическое ревью не нашло блокеров в коде; замечание о несинхронизированной документации исправлено. [Детали и границы](pilot.md#приёмка-из-чистого-клона).

**Роли Codex:** пять определений в `.codex/agents/`. `npx --yes --package=@openai/codex@0.172.0 -- codex --version` подтвердил версию, `codex login status` — доступность входа; определения проверены `tomllib`. В отдельном временном проекте `codex exec --enable multi_agent_v2 --json` реально вызвал Planner, Architect, Generator, Healer и Reviewer. `node --test exercise/publication.test.mjs` дал `1 failed` на намеренном сбое, после правки модуля — `1 passed` с неизменным тестом. Отдельный read-only Reviewer нашёл зависимые ожидания; Generator усилил тест, повторное ревью согласовало. Сырые журналы, настройки и упражнение не входят в Git. [Очищенная запись вызовов](codex-roles.md). Основные `src/` и `tests/` не менялись; `npm run typecheck` и `npm test` (`9 passed`) прошли.

**Ревью пилота:** отдельные неинтерактивные сессии Pi (`pi -p --no-session --no-tools …`) проверили сначала контракт, затем реализацию. Замечания закрыты: точное сравнение текста без нормализации, проверка метки по всей странице, окно очистки отсчитывается от события выхода Playwright и перепроверяется после TCP-пробы. Последняя сессия подтвердила снятие блокера. Ревьюеры читали документы и код, не запускали проверки и не правили файлы. Это не вызовы ролей Codex.
