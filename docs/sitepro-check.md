# Site.pro — проверка своей учебной страницы

**24 ноября 2026 UTC.** С разрешения владельца в текущем бесплатном плане настроен пустой шаблон и опубликована отдельная учебная страница на поддомене `*.free.site.pro`. Покупок не было. Это разовая проверка через штатный браузерный интерфейс, управляемый Playwright, а не прогон локального тестового набора. Прямой адрес опущен из публичного отчёта; команды и доказательства ниже не содержат данных аккаунта.

## Окружение и входные данные

macOS 15.7.4, Chrome 158.0.8127.88, Playwright 1.60.0-alpha-1774999321000. Автор — отдельный профиль Chrome, вход выполнен владельцем; посетитель — новые контексты без переноса состояния автора. Использован `node` с временными скриптами Playwright через `chromium.connectOverCDP` и штатные действия UI. Ссылки на внутренние API не использовались.

- Заголовок: `Учебная QA-страница`.
- V1: `Весенний выпуск готов. Эта страница создана для учебной проверки публикации.`
- V2: тот же абзац с добавленным в конце маркером `V2` (через пробел).

## Наблюдения

| Шаг | Ожидание | Фактический результат |
| --- | --- | --- |

Публичный адрес ответил HTTP 200, но ни заголовка, ни абзаца V1 там не было. |

| Добавить `V2`, выбрать «Сохранить», не публиковать | V2 сохраняется в редакторе, гость всё ещё видит V1 | После перезагрузки редактора V2 сохранилась; гость получил HTTP 200 и видел только V1. |

Отдельное ожидание видимого сообщения об успехе в редакторе истекло; обновление подтверждено по публичному URL. |

Это рабочие ожидания сценария, не утверждения о внутренних правилах Site.pro. Публичный HTTP 200 до первой публикации не считается дефектом: критерием было отсутствие текста черновика, а не код 404 из отдельного локального контракта. Первоначальный сетевой таймаут кабинета исчез после смены VPN; причина не установлена. Дефекты продукта в первом проходе не подтверждены. Ссылки и поля редактора проверены отдельным проходом ниже. Другие браузеры и реальные мобильные устройства не проверялись.

## Поля редактора и текстовая ссылка

**24 ноября 2026 UTC.** macOS 15.7.4, Chrome 158.0.8127.88, Playwright 1.64.1. Повторно использован авторизованный профиль владельца для штатного UI; посетитель проверялся в новых контекстах без входа. Не менялись тариф, настройки аккаунта или другие сайты.

В обоих случаях HTTP 200, URL получил `#qa-start`, якорь находится в заголовке, горизонтальной прокрутки нет. Заголовок и исходный абзац V2 сохранены. |

Кабинет подтвердил публикацию. Первый гостевой запрос после неё не показал ссылку в пределах короткого ожидания; в следующих свежих контекстах ссылка была видна и работала. Причина не установлена, дефект не подтверждён. Страница оставлена опубликованной с V2, заметкой и ссылкой.

**Ограничение тарифа:** конструктор пометил виджеты «Форма» и «Кнопка» как премиальные. Тариф не менялся, поэтому поля и отправка формы посетителя не проверены; письма и реальные данные не отправлялись. Проверены только перечисленные поля редактора и одна внутренняя текстовая ссылка. Локальный сервис и его тесты не менялись.
