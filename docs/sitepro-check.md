# Site.pro — проверка своей учебной страницы

**24 ноября 2026 UTC.** С разрешения владельца в текущем бесплатном плане настроен пустой шаблон и опубликована отдельная учебная страница на поддомене `*.free.site.pro`. Покупок не было. Это разовая проверка через штатный браузерный интерфейс, управляемый Playwright, а не прогон локального тестового набора. Прямой адрес опущен из публичного отчёта; команды и доказательства ниже не содержат данных аккаунта.

## Окружение и входные данные

macOS 15.7.4, Chrome 158.0.8127.88, Playwright 1.60.0-alpha-1774999321000. Автор — отдельный профиль Chrome, вход выполнен владельцем; посетитель — новые контексты без переноса состояния автора. Использован `node` с временными скриптами Playwright через `chromium.connectOverCDP` и штатные действия UI. Ссылки на внутренние API не использовались.

- Заголовок: `Учебная QA-страница`.
- V1: `Весенний выпуск готов. Эта страница создана для учебной проверки публикации.`
- V2: тот же абзац с добавленным в конце маркером `V2` (через пробел).

## Наблюдения

| Шаг | Ожидание | Фактический результат |
| --- | --- | --- |
| Внести V1 в редакторе, открыть предпросмотр, выбрать «Сохранить» и перезагрузить редактор | Предпросмотр показывает обе строки; черновик переживает перезагрузку; гость до публикации не видит новых данных | Обе строки видны в предпросмотре и после перезагрузки редактора. Публичный адрес ответил HTTP 200, но ни заголовка, ни абзаца V1 там не было. |
| Выбрать «Опубликуйте», открыть адрес без входа | Появляется опубликованное содержимое | В редакторе было сообщение «Сайт опубликован». В гостевых контекстах при 1280 и 360 px — HTTP 200, заголовок и точный абзац V1 видны; горизонтального переполнения нет. |
| Добавить `V2`, выбрать «Сохранить», не публиковать | V2 сохраняется в редакторе, гость всё ещё видит V1 | После перезагрузки редактора V2 сохранилась; гость получил HTTP 200 и видел только V1. |
| Повторно выбрать «Опубликуйте» и открыть адрес в новых гостевых контекстах | Видна V2 вместо V1 | При 1280 и 360 px — HTTP 200, видны заголовок и точная V2; точная V1 не отображалась, горизонтального переполнения нет. Отдельное ожидание видимого сообщения об успехе в редакторе истекло; обновление подтверждено по публичному URL. |

Это рабочие ожидания сценария, не утверждения о внутренних правилах Site.pro. Публичный HTTP 200 до первой публикации не считается дефектом: критерием было отсутствие текста черновика, а не код 404 из отдельного локального контракта. Первоначальный сетевой таймаут кабинета исчез после смены VPN; причина не установлена. Дефекты продукта не подтверждены. Ссылки в авторском контенте, валидация, другие браузеры и реальные мобильные устройства не проверялись. Страница оставлена опубликованной с V2.
